# 🚀 دليل تشغيل ونشر تطبيق MY AGENCY الكامل

تطبيق متكامل وشامل لإدارة استوديو **MY AGENCY** (تصميم جرافيك، مونتاج وفيديو، AI video، مواقع ويب، ومتاجر إلكترونية)، يشمل بوابة عملاء احترافية ولوحة تحكم إدارية متقدمة.

---

## 🎨 الهوية البصرية ونظام التصميم
- **الشعار**: مونوجرام هندسي متداخل للحرفين **M و A** بشكل شعلة وسهم مبتكر.
- **لوحة الألوان**:
  - `ink` (الخلفية الداكنة): `#0A0B14`
  - `surface` (الأسطح): `#12141F`
  - `primary` (برتقالي ناري): `#FF5B2E`
  - `secondary` (بنفسجي كهربي): `#6E3BFF`
  - `highlight` (ليموني نيون): `#C6FF3D`
  - دعم الوضع الفاتح (`#F6F5F2`) مع إمكانية التبديل اللحظي من إعدادات الحساب.

---

## 🔐 نظام المصادقة وإنشاء الحساب
1. **تسجيل الدخول**:
   - بالبريد الإلكتروني وكلمة المرور.
   - **الدخول السريع بحساب Google** عبر مكتبة `androidx.credentials.CredentialManager`.
   - استعادة كلمة المرور عبر رابط إلكتروني.
   - حماية من محاولات التخمين: قفل 60 ثانية بعد 5 محاولات خاطئة متتالية.
2. **التسجيل متعدد المراحل (5 خطوات)**:
   - الخطوة 1: الاسم الكامل (3 أحرف على الأقل).
   - الخطوة 2: رقمان مصريان صحيحان ومختلفان (01XXXXXXXXX) مع تحديد رقم الواتساب.
   - الخطوة 3: العنوان واختيار المحافظة من قائمة الـ 27 محافظة في مصر.
   - الخطوة 4: البريد وكلمة المرور (مؤشر قوة، وتأكيدها).
   - الخطوة 5: الموافقة على الشروط والخصوصية.

---

## 📱 تجربة العميل (5 تبويبات رئيسية + زر الدعم العائم)
1. **الرئيسية**: ملخص المشاريع الجارية، الفواتير، الإعلانات، عداد تنازلي للعروض الخاصة، واختصارات سريعة.
2. **مشاريعي**: فلترة وبحث، مراحل Stepper، معاينة الصور في Lightbox، تشغيل الفيديو، مستندات PDF، الجدول الزمني، وأزرار القرار (موافق / طلب تعديل)، وتقييم بالنجوم.
3. **الخدمات والمعرض**: أسعار الخدمات بالخصومات، كوبونات الخصم، إجمالي لحظي، وزر طلب مباشر يحفظ الطلب ويفتح واتساب.
4. **فواتيري**: طرق الدفع (فودافون كاش: `01508664132`، إنستاباي: `myagency@instapay`، تحويل بنكي)، رفع إيصال التحويل، وعرض الفاتورة الرسمية.
5. **حسابي**: تعديل البيانات، تبديل الثيم، إعدادات الإشعارات، وتسجيل الخروج.
6. **زر الدعم العائم (FAB)**: زر عائم دائم بنبض خفيف يفتح شات الدعم المباشر، أرقام الواتساب والاتصال، والأسئلة الشائعة.

## 🛠️ دليل إعداد وربط Firebase

### 1) إنشاء مشروع وتفعيل الخدمات
1. توجّه إلى [Firebase Console](https://console.firebase.google.com/).
2. أنشئ مشروعاً جديداً باسم `my-agency-app`.
3. من قائمة **Authentication**:
   - فعّل **Email/Password**.
   - فعّل **Google Sign-In**.
4. من قائمة **Firestore Database**:
   - أنشئ قاعدة بيانات في وضع الإنتاج.

### 2) نشر قواعد الأمان (firestore.rules)
انسخ محتوى ملف `firestore.rules` والصقه في تبويب **Rules** داخل Firestore واضغط **Publish**.

### 3) إنشاء أول أدمن للنظام
1. سجّل حساباً ببريدك الإلكتروني من التطبيق أو عبر Firebase Auth.
2. انسخ الـ `UID` الخاص بهذا الحساب.
3. في Firestore، أنشئ Collection جديدة باسم `admins`.
4. اجعل الـ Document ID هو الـ `UID` المنسوخ.
5. أضف الحقول:
   ```json
   {
     "role": "owner",
     "email": "info.lamsa.eg@gmail.com"
   }
   ```

1. **تكامل Jetpack Credential Manager**: تطبيق أحدث معايير جوجل لتسجيل الدخول السريع بحساب Google لحماية بيانات العميل وسرعة الانضمام.
